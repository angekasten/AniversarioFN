# 🥁 Missão: Feliz aniversário, baterista

Uma mini aventura em HTML feita de presente de aniversário.
Tem abertura no estilo Star Wars, um joguinho de coletar cartinhas e uma surpresa no final.

## ▶️ Como jogar

Abra pelo celular, de preferência na vertical, e toque em **INICIAR MISSÃO**.

## 🛠️ Tecnologias

- HTML, CSS e JavaScript puros, tudo em um único arquivo
- Fontes do Google Fonts: Press Start 2P e Montserrat
- Sem dependências, sem build

## 📁 Estrutura

```
.
├── index.html   # a página inteira (estilos e scripts incluídos)
└── README.md
```

## 🚀 Publicação

O projeto é um site estático, publicado no [Vercel](https://vercel.com).
Para rodar localmente, basta abrir o `index.html` no navegador.
